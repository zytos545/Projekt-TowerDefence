Projekt Tower Defence
Projekt gry typu Tower Defence wykonany w języku C++ z wykorzystaniem biblioteki SFML.

Opis gry
Celem gry jest obrona mapy przed kolejnymi falami przeciwników. Gracz może stawiać różne typy wieżyczek, które automatycznie atakują przeciwników poruszających się po wyznaczonej ścieżce.
W grze występują różne typy wieżyczek oraz przeciwników, system fal, punkty życia gracza, pieniądze, ulepszanie wieżyczek, pociski, efekty dźwiękowe oraz ekrany wygranej i przegranej.
